## Что такое маятник Фуко

Маятник Фуко — это длинный маятник, плоскость колебаний которого медленно
поворачивается из-за вращения Земли. Это явление называется **прецессией**.

Скорость поворота зависит от географической широты:

```
Ω_z = ω_Земли × sin(φ)
```

где `ω_Земли = 7.2921 × 10⁻⁵ рад/с`, `φ` — широта места.

- На полюсе (φ = 90°): плоскость делает полный оборот за 24 часа
- На экваторе (φ = 0°): прецессии нет
- В Москве (φ ≈ 56°): оборот за ~29 часов
- В Краснодаре (φ ≈ 45°): оборот за ~34 часа

## Установка и сборка

### macOS

```bash
# 1. Установить зависимости через Homebrew
brew install cmake sfml

# 2. Клонировать или распаковать проект
cd ~/Projects/FoucaultPendulum

# 3. Создать папку сборки и собрать
mkdir -p build && cd build
cmake ..
cmake --build .
```

### Windows (MinGW / MSYS2)

```bash
# 1. Установить MSYS2 (https://www.msys2.org/)
# 2. В терминале MSYS2:
pacman -S mingw-w64-x86_64-cmake mingw-w64-x86_64-sfml

# 3. Собрать
mkdir build && cd build
cmake .. -G "MinGW Makefiles"
cmake --build .
```

### Windows (Visual Studio)

```bash
# 1. Скачать SFML 3.0 с https://www.sfml-dev.org/download.php
# 2. Указать путь в cmake:
cmake .. -DSFML_DIR="C:/SFML/lib/cmake/SFML"
cmake --build . --config Release
```

### Linux (Ubuntu/Debian)

```bash
# 1. Установить зависимости
sudo apt-get install cmake libsfml-dev

# 2. Собрать
mkdir build && cd build
cmake ..
cmake --build .
```

## Подготовка шрифта

Программа требует шрифт с поддержкой латиницы. Рекомендуется **DejaVuSans**
(свободный шрифт, поддерживает все необходимые символы).

### Способ 1 — автоматически (скрипт)

```bash
# Из папки build:
bash ../get_font.sh
```

### Способ 2 — вручную

1. Скачать архив с [dejavu-fonts.github.io](https://dejavu-fonts.github.io/)
2. Распаковать
3. Скопировать файл `DejaVuSans.ttf` в папку `build/` (рядом с exe)

### Способ 3 — системный шрифт

Программа автоматически ищет шрифты в стандартных местах:

| ОС | Пути поиска |
|----|-------------|
| macOS | `/System/Library/Fonts/Supplemental/Arial Unicode.ttf` |
| Linux | `/usr/share/fonts/truetype/dejavu/DejaVuSans.ttf` |
| Windows | `C:/Windows/Fonts/arial.ttf` |

Если шрифт не найден, программа выведет сообщение в консоль и не запустится.

### Левая панель — Траектория

Отображает движение груза в горизонтальной плоскости в реальном времени.

- **Зелёная линия** — траектория канала A (широта Lat.A)
- **Фиолетовая линия** — траектория канала B (широта Lat.B), если включён
- **Красный шар** — текущее положение груза
- **Фиолетовая стрелка** — вектор силы Кориолиса (п. 11 ТЗ)
- **Крестик вверху** — точка подвеса маятника

### Индикатор прецессии (левый нижний угол)

Круговой компас показывает угол поворота плоскости колебаний:

- **Жёлтая стрелка** — текущее направление плоскости качания
- **Жёлтая дуга** — пройденный угол с начала симуляции
- **Число под кружком** — угол в градусах

### Правая панель — Три графика

| График | Цвет | Содержание |
|--------|------|------------|
| **x(t)** | Красный | Горизонтальная координата X vs время |
| **y(t)** | Зелёный | Горизонтальная координата Y vs время |
| **α(t)** | Жёлтый | Угол прецессии в радианах vs время |

На каждом графике:
- Полупрозрачная заливка под кривой
- Числовые значения минимума и максимума
- Живая точка в правом конце кривой

## Физика и алгоритмы

### Уравнения движения

В системе отсчёта, связанной с вращающейся Землёй, на груз действует:
- Сила тяжести (через упругость нити)
- **Сила Кориолиса**: `F = 2m(v × Ω)`

В проекции на горизонтальную плоскость уравнения движения:

```
ẍ = −ω₀² · x + 2Ω_z · ẏ
ÿ = −ω₀² · y − 2Ω_z · ẋ
```

где:
- `ω₀ = √(g/L)` — собственная частота маятника
- `Ω_z = ω_Земли · sin(φ)` — вертикальная составляющая угловой скорости Земли
- `φ` — географическая широта

### Метод Рунге-Кутты 4-го порядка

Численное интегрирование выполняется методом РК4, который обеспечивает
точность O(dt⁴) при каждом шаге:

```
k1 = f(t,  y)
k2 = f(t + dt/2,  y + dt/2 · k1)
k3 = f(t + dt/2,  y + dt/2 · k2)
k4 = f(t + dt,    y + dt · k3)

y(t+dt) = y(t) + dt/6 · (k1 + 2k2 + 2k3 + k4)
```

Состояние системы: вектор `[x, ẋ, y, ẏ]`.

### Угол прецессии

Теоретический угол поворота плоскости колебаний:

```
α(t) = −Ω_z · t = −ω_Земли · sin(φ) · t
```

## Типичные проблемы

**Программа не запускается — «Font not found»**
> Положите файл `DejaVuSans.ttf` в папку `build/` рядом с exe.
> Скачайте его скриптом: `bash ../get_font.sh`

**Текст в интерфейсе размытый (macOS Retina)**
> Это решено в коде через `window.mapPixelToCoords()` и `setView`.
> Если проблема остаётся — попробуйте шрифт `DejaVuSans.ttf` вместо системного.

**Кнопки нажимаются не там (macOS Retina)**
> Исправлено через `mapPixelToCoords` — все клики конвертируются в логические координаты.

**Ошибка CMake «SFML not found»**
> Укажите путь явно: `cmake .. -DSFML_DIR="/path/to/sfml/lib/cmake/SFML"`

**Предупреждение при сборке на macOS (array designator)**
> Это предупреждение о C99-расширении, исправлено в коде. Пересоберите `--clean-first`.
