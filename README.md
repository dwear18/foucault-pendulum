## Что такое маятник Фуко

Маятник Фуко — это длинный маятник, плоскость колебаний которого медленно
поворачивается из-за вращения Земли. Это явление называется **прецессией**,
и именно оно позволяет наглядно наблюдать вращение Земли без телескопов.

Скорость поворота зависит от географической широты:

```
Ω_z = ω_Земли × sin(φ)
```

где `ω_Земли = 7.2921 × 10⁻⁵ рад/с`, `φ` — широта места.

### Исторические маятники Фуко

| Место | φ | L | m | Период прецессии |
|-------|---|---|---|-----------------|
| Пантеон, Париж (1851) | 48.87° | 67 м | 28 кг | 31.8 ч |
| Исаакиевский собор, СПб | 59.9° | 98 м | 54 кг | 27.7 ч |
| Северный полюс | 90° | — | — | 24.0 ч |
| Краснодар (КубГУ) | 45° | — | — | 33.9 ч |
| Экватор | 0° | — | — | ∞ (нет прецессии) |

**Программа по умолчанию моделирует маятник Исаакиевского собора**
(Санкт-Петербург, φ = 59.9°) как канал A, и маятник Пантеона
(Париж, φ = 48.9°) как канал B для сравнения.

> **Историческая справка.** Именно в парижском Пантеоне в 1851 году
> Леон Фуко впервые публично продемонстрировал вращение Земли с помощью
> маятника длиной 67 м. До этого вращение Земли было известно лишь
> теоретически — Фуко сделал его видимым для любого зрителя.

## Подготовка шрифта

Программа требует шрифт с поддержкой латиницы. Рекомендуется **DejaVuSans**
(свободный шрифт, поддерживает все необходимые символы).

### Способ 1 — автоматически (скрипт)

```bash
# Из папки build:
bash ../get_font.sh
```

### Способ 2 — вручную

1. Скачать архив с [dejavu-fonts.github.io](https://dejavu-fonts.github.io/)
2. Распаковать
3. Скопировать файл `DejaVuSans.ttf` в папку `build/` (рядом с exe)

### Способ 3 — системный шрифт

Программа автоматически ищет шрифты в стандартных местах:

| ОС | Пути поиска |
|----|-------------|
| macOS | `/System/Library/Fonts/Supplemental/Arial Unicode.ttf` |
| Linux | `/usr/share/fonts/truetype/dejavu/DejaVuSans.ttf` |
| Windows | `C:/Windows/Fonts/arial.ttf` |

Если шрифт не найден, программа выведет сообщение в консоль и не запустится.

### Шапка (верхняя панель)

| Элемент | Описание |
|---------|----------|
| **Speed** | Текущий множитель скорости симуляции (1.0x … 1000.0x) |
| **Time** | Прошедшее модельное время в формате ЧЧ:ММ:СС |
| **Lat.A** | Широта основного маятника (канал A), по умолчанию 59.9° |
| **Lat.B** | Широта второго маятника (канал B), по умолчанию 48.9°, или «off» |
| **Status** | `> Running` или `|| Pause` |
| **[P] Params** | Кнопка открытия панели параметров |

### Левая панель — Траектория

Отображает движение груза в горизонтальной плоскости в реальном времени.

- **Зелёная линия** — траектория канала A (широта Lat.A, Исаакиевский собор)
- **Фиолетовая линия** — траектория канала B (широта Lat.B, Пантеон), если включён
- **Красный шар** — текущее положение груза
- **Стрелка** — вектор силы Кориолиса
- **Крестик вверху** — точка подвеса маятника

За первый час работы траектория образует характерную **розетку из лепестков**.
За 24 часа лепестки полностью заполняют круг — это физически корректное поведение
реального маятника Фуко.

### Индикатор прецессии (левый нижний угол)

Круговой компас показывает угол поворота плоскости колебаний:

- **Жёлтая стрелка** — текущее направление плоскости качания
- **Жёлтая дуга** — пройденный угол с начала симуляции
- **Число под кружком** — угол в градусах (например, `-13.01 deg` за 1 час при φ=59.9°)

Знак «минус» означает поворот по часовой стрелке — корректное направление
для Северного полушария.

### Правая панель — Три графика

| График | Цвет | Содержание |
|--------|------|------------|
| **x(t)** | Красный | Горизонтальная координата X (м) vs время |
| **y(t)** | Зелёный | Горизонтальная координата Y (м) vs время |
| **α(t)** | Жёлтый | Угол прецессии (рад) vs время — прямая линия с постоянным наклоном |

На каждом графике:
- Полупрозрачная заливка под кривой
- Числовые значения минимума и максимума по оси Y
- Живая точка в правом конце кривой

### Кнопки мгновенной перемотки

```
[1h]   [6h]   [12h]   [24h]
```

Вычисляют состояние симуляции через указанное время **мгновенно**, без анимации,
методом РК4 с сохранением точности. Удобны для быстрой проверки значений угла
прецессии и сравнения с эталонными значениями.

| 12 ч  | 156.20°  | −156.15°    | 0.05° (0.03%) |

Полный оборот плоскости колебаний — за **≈ 27.7 часа** (совпадает с историческими данными).

### Как проверить самостоятельно

1. Запустить программу с параметрами по умолчанию (Исаакиевский собор, φ = 59.9°)

## Физика и алгоритмы

### Уравнения движения

В системе отсчёта, связанной с вращающейся Землёй, на груз действует:
- Сила тяжести (через упругость нити)
- **Сила Кориолиса**: `F = 2m(v × Ω)`

В проекции на горизонтальную плоскость уравнения движения:

```
ẍ = −ω₀² · x + 2Ω_z · ẏ
ÿ = −ω₀² · y − 2Ω_z · ẋ
```

где:
- `ω₀ = √(g/L)` — собственная частота маятника
- `Ω_z = ω_Земли · sin(φ)` — вертикальная составляющая угловой скорости Земли
- `φ` — географическая широта

### Метод Рунге-Кутты 4-го порядка

Численное интегрирование выполняется методом РК4, который обеспечивает
точность O(dt⁴) при каждом шаге:

```
k1 = f(t,        y)
k2 = f(t + dt/2, y + dt/2 · k1)
k3 = f(t + dt/2, y + dt/2 · k2)
k4 = f(t + dt,   y + dt   · k3)

y(t+dt) = y(t) + dt/6 · (k1 + 2k2 + 2k3 + k4)
```

Состояние системы: вектор `[x, ẋ, y, ẏ]`.

### Угол прецессии

Теоретический угол поворота плоскости колебаний:

```
α(t) = −Ω_z · t = −ω_Земли · sin(φ) · t
```

### Мгновенная перемотка (кнопки 1h / 6h / 12h / 24h)

При нажатии кнопки перемотки программа прогоняет цикл РК4 без отрисовки,
используя тот же шаг dt = 0.01 с. Это гарантирует, что численная точность
полностью совпадает с результатом анимации при той же длительности симуляции.

### Биения амплитуды (beating effect)

На графиках x(t) и y(t) при длительной симуляции (12–24 часа) видны
периодические изменения амплитуды. Это **физически корректное явление**:
энергия колебаний медленно перекачивается между осями X и Y по мере
поворота плоскости колебаний. Не является артефактом численного метода.

## Типичные проблемы

**Программа не запускается — «Font not found»**
> Положите файл `DejaVuSans.ttf` в папку `build/` рядом с exe.
> Скачайте его скриптом: `bash ../get_font.sh`

**Текст в интерфейсе размытый (macOS Retina)**
> Решено в коде через `window.mapPixelToCoords()` и `setView`.
> Если проблема остаётся — попробуйте шрифт `DejaVuSans.ttf` вместо системного.

**Кнопки нажимаются не там (macOS Retina)**
> Исправлено через `mapPixelToCoords` — все клики конвертируются в логические координаты.

**Ошибка CMake «SFML not found»**
> Укажите путь явно: `cmake .. -DSFML_DIR="/path/to/sfml/lib/cmake/SFML"`

**Предупреждение при сборке на macOS (array designator)**
> Предупреждение о C99-расширении, не влияет на работу. Пересоберите `--clean-first`.

**После кнопки `24h` амплитуда маятника нестабильна**
> Убедитесь, что dt ≤ 0.01 с. При слишком большом шаге интегрирования
> метод РК4 теряет точность. Рекомендуемое значение — dt = 0.01 с.
